# Third-party notices

Voople depends on third-party packages whose licences remain their own. The
root AGPL licence does not relicense those packages, fonts, codecs, SDKs, or
native libraries.

The authoritative dependency set is recorded in the npm and Cargo lockfiles.
Before each public binary release, the project must generate and review a
machine-readable SBOM and a dependency-licence report, then include every notice
required by the shipped dependency set.

This file establishes that release obligation; it is not yet an exhaustive
inventory and must not be treated as one.
