# Модерация и жалобы

## Жалобы на посты (`post_reports`)

### Куда попадает жалоба

1. Пользователь жмёт **Пожаловаться** в меню поста (`post.report`).
2. Сервер пишет строку в `post_reports` через **service role** (RLS для браузера закрыт).
3. Поля: `post_id`, `reporter_user_id`, `reason` (пока не спрашиваем в UI), `created_at`.
4. Повторная жалоба того же пользователя на тот же пост → ошибка «Вы уже отправили жалобу».

**Сейчас нет:** админ-панели, уведомлений модераторам, автоматического скрытия поста, бана автора.

### Последствия для пользователей (текущая версия)

| Что происходит | Что не происходит |
|----------------|-------------------|
| Жалоба сохраняется в БД | Пост не скрывается |
| Автор видит toast «Жалоба отправлена» | Автор поста не уведомляется |
| Один reporter — одна запись | Нет публичного счётчика жалоб |

Планируемый pipeline (не реализован): очередь для модераторов → review → `hidden` / предупреждение / ban. До этого жалобы — только накопление данных.

### Запросы для разработки

```sql
-- последние жалобы с постом
SELECT r.*, p.author_id, p.text
FROM post_reports r
JOIN posts p ON p.id = r.post_id
ORDER BY r.created_at DESC
LIMIT 50;
```

Миграция: `drizzle/16-post-edit-reports.sql`.
